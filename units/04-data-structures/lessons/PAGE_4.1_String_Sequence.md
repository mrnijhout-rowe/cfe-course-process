## What happened in class

A string is a sequence of characters, and a `for` loop can visit them
one at a time. `for letter in word:` hands you each character in turn,
with no `range` and no position to keep track of. Mr. Nijhout-Rowe
turned that loop into a counter: `count` starts at 0 and grows by 1
with `count += 1` each time a character passes a test. `len(word)`
gives the number of characters in a string, and `'s' in word` asks
whether a piece of text is inside it. You wrote a vowel counter on your
own, and pairs built a letter counter of their own design.

The comparison table of data structures started today. You copied the

first cells of the String column. The other columns fill in as the unit
