# Unit 1: Information (pointer)

Unit 1 was built and taught in the first-build repository and is
unchanged. It lives at:

    ../../../cfe_redesign/units/01-information/

Eight 50-minute lessons: information as data plus context, declarative
description, imperative instructions, Knuth's properties of algorithms,
binary place value and fluency, designing a text code (students
reinvent the ASCII problem), then Quiz 1 and first contact with Python.
Readings R1 through R4 and the Fab Lab manipulatives are in that folder.

Nothing from that folder is copied here, and nothing here depends on
its contents beyond the fact that students arrive in Unit 2 knowing
binary, ASCII, and what an algorithm's five properties are.
